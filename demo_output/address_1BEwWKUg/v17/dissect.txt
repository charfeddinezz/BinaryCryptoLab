Closed questions
  - If the output is ever spent and its public key becomes public, the remaining barrier becomes the p2pkh discrete logarithm, about 2^128 classical operations.

Caveats
  - Costs are operation counts for the best publicly known classical algorithms, not wall-clock promises: hardware assumptions change the constant, never the exponent.
  - Grover's algorithm lowers a 2^160 preimage search to about 2^80 quantum operations, which is still infeasible and requires a fault-tolerant machine that does not exist.
  - Shor's algorithm would solve the discrete logarithm in polynomial time on a large fault-tolerant quantum computer. No such machine exists at the required scale, and published resource estimates remain contested. If one were built, secp256k1 would fail outright rather than degrade.
  - RIPEMD-160 collision resistance is weaker than its preimage resistance; this asymmetry is why the hash step is quoted at 2^160 and not at the collision bound.

Notes
  - Only public data is analysed. No key material is present in an address.
  - The checksum was recomputed independently, not just compared.
  - The scriptPubKey shown is the one this output pays to; no chain data is read.
  - The randomness battery tests the payload as a bit string. A hash should look random, so failures indicate padding or construction, not weakness of the key.
  - The same version byte is registered on several chains, so the chain is reported as a set rather than a fact.

Limitations
  - An address does not reveal its public key, and the report never claims one.
  - Ownership, balance, and history require chain data; audit-address-data can read a file you supply yourself, but this command reads nothing.
  - Structural statistics describe the payload, not the security of the generator that produced the key behind it.
  - A clean report does not prove the output is safe to receive funds at.

Warnings:
  - An address is not a public key; no key material is derived or claimed.
  - Ownership, balance, and history require chain data. This tool reads none.
