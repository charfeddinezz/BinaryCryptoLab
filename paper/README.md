# The paper and its artefacts

Everything in this directory is generated by [`reproduce.py`](reproduce.py) except the
two manuscripts. Nothing here is fetched from the network.

| Path | What it is |
| --- | --- |
| [`cross_logarithm_en.md`](cross_logarithm_en.md) | The paper, English |
| [`cross_logarithm_ar.md`](cross_logarithm_ar.md) | The paper, العربية |
| [`reproduce.py`](reproduce.py) | Driver: measurement, audit, cost models, figures |
| `data/measurement.json` | Six sizes × 15 verified trials, the fit, BSGS, and the positive control |
| `data/assessment.json` | The verdict, its evidence lines, the rebuttals, the falsifiers, and the address chain |
| `data/audit.json` | Ten structural properties with the value measured for each |
| `data/cost_models.json` | ECDLP, finite-field DLP, and the address stages |
| `data/claims.json` | The eight claims and the five falsifiers, verbatim from the code |
| `figures/fig_scaling.svg` | Measured growth against the `√q` reference |
| `figures/fig_control.svg` | The smooth-order positive control |
| `figures/fig_costs.svg` | Every relevant attack cost, side by side |

## Reproduce

```bash
python paper/reproduce.py
```

Expected, in about eight seconds:

```text
measuring Pollard rho at (12, 16, 20, 24, 28, 32) with 15 trials each ...
  slope = 0.4973 +/- 0.0153
  R^2   = 0.9962
  z     = -0.18
  extrapolated 256-bit cost = 2^128.7
  verdict: not refuted
  field DLP at 256 bits = 2^46.7
  address preimage step = 2^160.0
  address stage-exponent sum = 2^288.0
  audit: 10 properties, 0 exploitable
```

The driver is deterministic (fixed seed, derivations from the trial index, sequential
trials), so re-running it reproduces the committed JSON byte for byte.
`tests/test_reproduce.py` enforces that.

## Scope

The study solves toy instances only; secp256k1 is never searched. The 256-bit figures
are an extrapolation of the measured exponent plus published cost formulae, and the
paper states what that can and cannot support. See
[`../docs/dlp_audit.md`](../docs/dlp_audit.md) for the command-level reference.
